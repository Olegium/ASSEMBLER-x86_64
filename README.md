# ASSEMBLER-x86_64

[rsp+20h]  указатель на вершину стэка

[rbp-58h]  Указывает на (начало) стека функции.Значение RBP остается неизменным на время выполнения функции

==============================================================================

push rbp        ; 1. Сохраняем старый базовый указатель (адрес кадра вызывающей функции) в стеке

mov rbp, rsp    ; 2. Делаем так, чтобы RBP указывал на текущую вершину стека (теперь это основание нового кадра)

sub rsp, 80h    ; 3. Выделяем место в стеке для локальных переменных (сдвигаем RSP вниз на 0x80 байт)

================================================================================
